# capabilities-data Specification

## Purpose

能力与接入页是治理者看「这个租户到底有什么能力」的窗口：每一块必须来自真实读口，
有就列、没有就说真 0、读不到就报故障——三种状态永不互相冒充。

## ADDED Requirements

### Requirement: 工具清单来自真实读口

The system SHALL 从工具组的真实清单读取工具能力数据；上游不存在的路由 SHALL NOT
继续作为取数来源，其 404 结果 SHALL NOT 被渲染为空清单。

#### Scenario: 上游有工具组数据
- **WHEN** 工具组清单返回非空集合
- **THEN** 页面按组呈现工具行，计数与回包一致

#### Scenario: 读口不可达
- **WHEN** 工具清单读失败（网络故障、非 2xx、或形制无法解析）
- **THEN** 页面呈现失败态与原因，提供重试，不显示「暂无工具」

### Requirement: 模型目录按供应商摊平且计数可核对

The system SHALL 从模型目录真读口取数，把「供应商 × 模型」摊平为行上屏；
目录行的供应商归属与总数必须可与回包核对。

#### Scenario: 目录含多供应商
- **WHEN** 模型目录回包包含多个供应商、每个供应商携带模型清单
- **THEN** 页面逐供应商摊平模型行，每行标明归属供应商
- **AND** 目录计数等于摊平后的行数

#### Scenario: 回包不是预期的目录形制
- **WHEN** 回包缺少供应商数组、无法按目录解析
- **THEN** 页面判为读口缺失并如实声明，不按通用键猜测渲染空表

### Requirement: 价目与模型目录同源

The system SHALL 从模型目录同包读取价目并上屏；目录未随包价目时
SHALL NOT 出现编造的价目行，页面写明价目未接线。

#### Scenario: 目录随包价目
- **WHEN** 供应商条目携带价目映射
- **THEN** 价目表按「供应商/模型」成行，金额与回包一致

#### Scenario: 目录无随包价目
- **WHEN** 供应商条目没有价目映射
- **THEN** 价目块声明「未接线」，不显示空表冒充「免费」或 0

### Requirement: 上游故障不得伪装成空集

The system SHALL 把上游拒绝服务（含需要重启一类的保护态）原样呈现为故障；
SHALL NOT 为规避故障而切换到会返回空结果的备用取数路径。

#### Scenario: 目录口返回拒绝服务
- **WHEN** 模型目录读口返回 5xx（如进程代码落后要求重启）
- **THEN** 页面显示故障与原因、提供重试，模型表不落「0 个模型」

### Requirement: 真 0 必须说破

The system SHALL 在清单确认为上游返回的空集合时，明确表述为「真实为空，
不是加载失败」；故障、缺读口、真 0 三种状态 SHALL 使用可区分的文案。

#### Scenario: MCP 当前没有任何服务器
- **WHEN** MCP 服务器清单读口成功返回空集合
- **THEN** 页面写明清单是空的且是真零，而非加载中或读取失败

#### Scenario: 缺读口的块
- **WHEN** 某能力块没有可用读口
- **THEN** 该块声明缺读口，不画示例行、不把缺读口计为 0

### Requirement: 提案队列只认提案台账

The system SHALL 从提案台账读取提案队列；台账未接通期间，提案块 SHALL 按
缺读口如实呈现，接通后按台账真值列行。

#### Scenario: 台账未接通（当前状态）
- **WHEN** 提案台账读口尚未指向真实服务
- **THEN** 提案块声明缺读口，页面不出现编造的提案行

#### Scenario: 台账接通后
- **WHEN** 提案台账返回若干提案
- **THEN** 提案队列逐行列出，计数与台账一致，空集时写明真零
