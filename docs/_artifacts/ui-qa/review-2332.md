### 2. 取图与两个必须记录的方法坑
`npx playwright screenshot --viewport-size=1440,2600 --wait-for-timeout=10000 --full-page --load-storage <auth-state> <url> <out>.png`（375 档用 375,3200）。

- **`--full-page` 对本应用是 no-op**：v4 shell 在内部 overflow 容器滚动，输出恒为视口尺寸，fold 以下从未入镜。修法：宽度不变、**加高视口**（1440×2600 / 375×3200），文件名宽度档保持 `<page>-<1440|375>-<HHMM>.png`。
- **并发截图会出全黑图**：多路并发曾产出 16KB 空图。改为**顺序拍摄 + 体积门槛（>40KB 否则重拍）**。
