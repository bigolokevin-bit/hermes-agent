## 7. 取证边界

1. 台账 `base` 是 `http://127.0.0.1:9122`，与派单要求的现网 8183 不一致；我全部复现跑在现网 8183。
2. 台账 auth 面用已过期 `v4-auth-state.json`，导致 auth≈anon；派单指定沿用该态，我因此同时跑了有效态作对照。
3. 台账不落逐路由 console 原文（summary 无 `consoleErrorSample` 键），故「首堆栈」在台账侧不存在；我侧 24 次采样 `pageerror`=0、堆栈=0。
4. `ENV_NOISE_RE` 只识别 Chrome 的两种 reason-phrase（`401 (Unauthorized)` / `404 (Not Found)`），403、5xx、`net::ERR_ABORTED` 均会被计为 product；行文本先截 160 再判，长 URL 也可能漏判。
5. 占位 id 路由（`:employeeId`）在台账与我的复现里都指向不存在的实体，不能当作真实用户路径的证据。
6. 匿名采样时页面停在会话过期/未接入态，DOM 规模与 auth 有效面不可比。
7. 本件代次一致（台账与现网同为 Chru2g4H），无跨代读数风险。
8. 早前一条交叉核对用了错误前缀的 `grep`（2 空格）导致命中 0，属假阴性，不作为「零非 ENV 行」的依据；该依据改由「三面 `productLinesTotal` 全 0 + 三面 texts 唯一一句 401 + 有效面逐行 404 清单」共同支撑（§3）。
