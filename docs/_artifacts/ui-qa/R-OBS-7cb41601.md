1. **台账 base 与派单要求不一致**：两面 `base=http://127.0.0.1:9122`，派单要求现网 8183。本文所有实测读数都在现网 8183 上取得；台账行数只作对照。

3. **台账 auth 面用的是已过期登录态**（`authStateFile` 指向 `v4-auth-state.json`，其 JWT `exp` 已过期）→ 在它名下 auth 面 ≈ anon 面，这正是「auth 面 `#/system` 记 5 行」而有效登录态实测 0 行的原因；同理 access 1440 档 err=10 是过期态里两轮 401/404 叠加，不属产品变化。

5. `#/system` 的 obs 在 auth/anon 两面 index 里都有 err=5，但只有 anon 面进 obs，说明 auth 面那 5 行被判 env-only、anon 面同样 5 行却进了 obs——两面判定不一致，属台账自身口径边界（可能与过期态下的行序/截断有关），本文不据以推断产品差异。
6. 派单提到的 `80bc8f62`（wave-107）在本次 merge 后不是 HEAD 祖先，其台账未读；本件按已入树的 `7cb41601` 代回答。
