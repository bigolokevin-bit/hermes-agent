### 6. 系统性根因（六页共性的最省事线索）

现网 `getComputedStyle(document.documentElement).fontSize` 实测 **15px**（`web/src/index.css` 的 `--theme-base-size` 覆写 html 字号，主题上下文再用 `typo.baseSize` 下发）。后果是所有 rem 派生的间距/字号整体缩水 6.25%，与 px 字面量令牌并存两套尺度：

| 名义（rem 档） | 实测渲染 | 令牌档应为 |
|---|---|---|
| 0.25rem | 3.75px | 4px |
| 0.5rem | 7.5px | 8px |
| 0.75rem | 11.25px | 12px |
| 1rem | 15px | 16px |
| 1.25rem | 18.75px | 20px |

这解释了六页反复出现的「间距不在 4/8/12/16/24/32 档」「th 内缩 16px vs 契约 12px」「标签 11.25px」「h1 16.875px vs 区块头 18.75px」——不是每处各自写错，而是两套尺度同时生效。**改法（不在本拍范围，仅登记）**：把根字号统一为 16px，或让间距/字号一律引用 px 令牌，二选一都能一次性消掉跨页的多条 P2 杂值条目。附带观察：`--color-text-muted` 读到 8 位带 alpha 值（`#ffe6cbad`），若非有意，建议核对。
